**Veda Technology — Cyber Security Internship (Day 8, Task 8)**

## Objective
Understand malware classification by studying major malware categories and their typical effects.

## Tools Used
- Browser
- Google Docs (for documentation)

## Approach
1. Researched the major malware categories: virus, worm, trojan, spyware, and ransomware.
2. Identified how each type spreads, its typical payload/effect, and real-world examples.
3. Compared the categories side by side to highlight key differences.
4. Compiled findings into a malware comparison table.

## Deliverable: Malware Comparison Table

| Malware Type | How It Spreads | Needs Host File? | Typical Effect |
|---|---|---|---|
| Virus | Attaches to files/programs, spreads when executed | Yes | Corrupts/modifies files, spreads on execution |
| Worm | Self-replicates across networks, no user action needed | No | Consumes bandwidth/resources, spreads rapidly |
| Trojan | Disguised as legitimate software | No | Opens backdoors, steals data, enables remote access |
| Spyware | Bundled with downloads or malicious links | No | Secretly monitors activity, steals credentials/data |
| Ransomware | Phishing emails, malicious downloads, exploits | No | Encrypts files, demands payment for decryption |

## Outcome
Gained a clear understanding of how different malware families are classified, how they propagate, and the effects they have on infected systems.

## Interview Questions (Reference)
**Q: What is malware?**
A: Malicious software designed to damage, disrupt, or gain unauthorized access to a computer system or data.

**Q: What is a trojan?**
A: Malware disguised as legitimate software that tricks users into installing it, then performs harmful actions like data theft or creating backdoors.

**Q: How is a worm different from a virus?**
A: A worm self-replicates and spreads across networks independently, while a virus needs a host file and user action (like opening it) to spread.
